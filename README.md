# Riyadh Restaurants Spatial Analysis

This project is a requirement for the **Tuwaiq Spatial Data Science Bootcamp**.  
The repository includes multiple components for spatial, statistical, and interactive analysis of restaurant data in Riyadh.

---

## Project Components

### 1. Streamlit Dashboard (Web App)
An interactive dashboard for exploring restaurant distribution, categories, and geospatial patterns in Riyadh.

**Live App:**  
https://project1-2ts7k9gzappchdsngidgl2v.streamlit.app/

---

### 2. Kepler.gl Map – Clipped Riyadh Restaurants
A Kepler.gl visualization showing clipped restaurant locations across Riyadh districts.

**Kepler Map:**  
https://mesha4545a.github.io/project1/

---

### 3. Google Colab Notebook – Exploratory Data Analysis (EDA)
A Colab notebook used for data cleaning, preprocessing, spatial joins, and exploratory data analysis.

**Colab Notebook:**  
https://colab.research.google.com/drive/1CsKpvss5xY2Di3lz0wrexwTjmH_V6U6W?usp=sharing
